# 扩散模型与图像生成

> 第40课知识笔记 | 2026-05-19

## 核心原理

扩散模型（Diffusion Model）通过两个互逆过程实现图像生成：

1. **前向扩散**：逐步给清晰图像添加高斯噪声，直到变成纯噪声
2. **反向去噪**：训练神经网络从噪声中逐步恢复原图

### 关键公式

| 概念 | 公式 | 说明 |
|------|------|------|
| 前向加噪 | x_t = √ᾱ_t · x₀ + √(1-ᾱ_t) · ε | ᾱ_t = Π(1-βᵢ)，噪声调度 |
| 训练损失 | L = E_{t,x₀,ε}[‖ε - ε_θ(x_t, t)‖²] | MSE 预测噪声 |
| 反向一步 | x_{t-1} = μ_θ(x_t, t) + σ_t · z | 去噪 + 微量随机性 |
| CFG 引导 | ε_guided = ε_uncond + s(ε_cond - ε_uncond) | s 为引导强度 |

### U-Net 架构

```
编码器: Conv64 → Conv128 → Conv256 → Conv512（下采样）
瓶颈层: Attention(512) + 时间嵌入 t
解码器: Conv512 → Conv256 → Conv128 → Conv64（上采样）
跳跃连接: 编码器特征 → 解码器对应层
```

### Stable Diffusion 架构（潜空间扩散）

| 组件 | 功能 | 维度变化 |
|------|------|----------|
| VAE Encoder | 像素→潜空间 | (3,512,512) → (4,64,64) |
| U-Net + CrossAttn | 条件去噪 | (4,64,64) → (4,64,64) |
| CLIP Text Encoder | 文本→嵌入 | text → (77,768) |
| VAE Decoder | 潜空间→像素 | (4,64,64) → (3,512,512) |

## 生成模型演进

| 类型 | 年份 | 优点 | 缺点 |
|------|------|------|------|
| VAE | 2013 | 结构化潜空间 | 模糊 |
| GAN | 2014 | 锐利 | 训练不稳定 |
| 扩散 | 2020 | 稳定+高质量 | 采样慢 |
