# 推理模型与思维链

## 🎯 核心概念

### 1. 基础定义
- **类型**：推理能力增强 / Prompt Engineering / RL 训练
- **适用场景**：多步数学推理、代码生成、科学分析、复杂规划
- **一句话定义**：通过显式化中间推理步骤（CoT）或 RL 训练推理能力（推理模型），让 LLM 从"直觉反应"进化到"逐步思考"

### 2. 数学原理
- CoT 准确率：P(正确) = ∏(1 - ε_i)，ε_i 为每步错误率
- 推理 token 与准确率关系：Accuracy ≈ a + b × log(tokens)
- PRM 奖励：R = Σ PRM(step_i)，对每步推理打分
- Self-Consistency：answer = mode({cot_1, ..., cot_n})，投票取众数

### 3. 实践要点
- 简单任务不需要推理模型（成本和延迟都高）
- Zero-shot CoT 用"Let's think step by step"即可触发
- 推理模型的 RL 训练需要可自动验证的答案（数学、代码）
- 推理 token 消耗是普通 LLM 的 10-50 倍

## 📊 关键公式

| 公式 | 含义 | 直觉 |
|------|------|------|
| P(全对) = ∏ P(step_i) | 多步推理全对概率 | 每步都对才全对 |
| Accuracy ∝ log(tokens) | 思考量与准确率关系 | 翻倍思考量增加固定准确率 |
| R = Σ PRM(step_i) | 过程奖励 | 每步推理都有分数 |
| answer = mode({cot_n}) | 自洽性投票 | 多数投票提升鲁棒性 |
| cost = tokens × price | 推理成本 | 思考量×单价 |

## 💡 记忆技巧
推理模型就像一个学会了"打草稿"的学霸——不是直接写答案，而是先把思路理清楚，错了还能擦了重来。关键发现：这个"打草稿"的能力可以通过 RL 训练自发涌现。
