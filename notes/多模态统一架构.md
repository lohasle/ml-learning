# 多模态统一架构

## 🎯 核心概念

### 1. 基础定义
- **类型**：多模态模型架构 / 视觉-语言融合
- **适用场景**：图文对话、视觉问答（VQA）、文档理解、多模态助手
- **一句话定义**：把图像、文本、音频统一编码成 token 序列，交给同一个 Transformer 处理

### 2. 数学原理
- 视觉 token 化：图像 → ViT(patch) → 投影层 → 视觉 token 向量
- 投影层：$z_v = W_{proj} \cdot v_{vit}$（把视觉特征翻译成语言模型维度）
- 统一序列：$X = [z_{v_1},...,z_{v_N}, t_1,...,t_M]$（视觉与文本拼接）
- 跨模态注意力：文本 token 通过自注意力自动「看」视觉 token

### 3. 实践要点
- 投影层用 2 层 MLP（LLaVA-1.5）比单层 Linear 融合更好
- 视觉 token 过多时用 Q-Former 压缩到固定数量（BLIP-2 用 32 个 query）
- 原生多模态训练需解决不同模态的梯度尺度、数据配比问题

## 📊 关键公式

| 公式 | 含义 | 直觉 |
|------|------|------|
| 图像 → ViT → Projector → 视觉token | 视觉 token 化流程 | 把一张图切成小块，每块变成一个向量，像「图块句子」 |
| $z_v = W_{proj} \cdot v_{vit}$ | 投影层 | 把视觉特征翻译成语言模型能理解的维度 |
| $X = [z_{v_1..N}, t_{1..M}]$ | 统一序列拼接 | 视觉和文本 token 不分你我，拼成一条 |
| $\text{Attn}(T_i, V_j)$ | 跨模态注意力 | 文本 token 自动「看」视觉 token |
| $L = -\sum \log P(t_k | X_{<k})$ | 语言建模目标 | 模型被迫从视觉 token 提取信息来回答 |

## 🔗 关联概念
- **前置知识**：Transformer 自注意力（第16课）、CLIP 对比学习（第21课）、ViT 视觉 Transformer
- **后续应用**：Any-to-Any 模型（Chameleon）、多模态 Agent、文档理解系统
- **同类对比**：
  - vs CLIP：CLIP 只对齐（检索），统一架构能生成（对话）
  - vs DiT：DiT 做视觉生成，统一架构做视觉理解
  - 三路线递进：LLaVA 拼接 → GPT-4V 深度联合 → Gemini 原生统一

## 💡 记忆技巧
**「一切皆 token」**——Transformer 是个只认 token 序列的机器。文本有 tokenizer，图像有 ViT+投影层。把两者拼成一条序列，自注意力会自动让它们「互相看见」。投影层就是那个翻译官。
