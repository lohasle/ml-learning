# 关键论文精读

> 三篇塑造当今 AI 的里程碑论文：Attention Is All You Need / BERT / InstructGPT

## 论文速览

| 论文 | 年份 | 核心创新 | 一句话 |
|------|------|----------|--------|
| Attention Is All You Need | 2017 | Self-Attention 架构 | 抛弃 RNN，纯靠注意力 |
| BERT | 2018 | Masked LM 双向预训练 | 完形填空，定义预训练-微调范式 |
| InstructGPT | 2022 | RLHF 三步流程 | 用人类反馈让模型"听话" |

## 核心公式

| 公式 | 出处 | 含义 |
|------|------|------|
| $Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$ | Transformer | 每个 token 检索所有 token，加权汇总 |
| $PE(pos,2i) = sin(pos/10000^{2i/d})$ | Transformer | 位置编码，注入序列位置信息 |
| MLM Loss = CrossEntropy(masked_tokens) | BERT | 预测被遮蔽的 token |
| $R_{reward} = RM(prompt, response)$ | InstructGPT | 奖励模型给回答打分 |

## 演进关系

```
Transformer (2017)
├── BERT (2018): Encoder-only + 双向预训练
├── GPT-1/2/3 (2018-2020): Decoder-only + 单向生成
│   └── InstructGPT (2022): GPT-3 + RLHF
│       └── ChatGPT / GPT-4 / Claude
└── ViT (2020): Transformer 进军视觉
```

## 阅读建议

每篇论文读 3 遍：
1. **第一遍**：Abstract + Introduction + 结论，抓大意
2. **第二遍**：Method + Experiments，看方法和实验设计
3. **第三遍**：数学细节 + Appendix，深入理解
