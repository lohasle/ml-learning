    项目全景

    任务：新闻文本多分类（体育/科技/娱乐/政治/财经）

    用 4 种方法解决同一个问题，形成梯度对比：

    | 方法 | 代表技术 | 对应课程 | 训练速度 | 预期效果 |

    方法演进的直觉

    把这 4 种方法想象成"认字"的四个层次：

  • **TF-IDF + LR**：数关键字频率（"球""队""比赛"出现多 → 体育）
  • **随机森林**：多棵决策树投票，每棵看不同的字组合
  • **TextCNN**：用卷积核捕捉"字组合模式"（如"击败对手"是体育特征）
  • **BERT 微调**：已经读懂了全网文本的"理解力"，再针对新闻分类做专训

    • 关键机制

    特征工程：从文本到数字

    
文本 → TF-IDF 向量化 → 稀疏矩阵 → 机器学习模型
文本 → 字符序列 → Embedding → CNN/RNN/Transformer
文本 → Token → 预训练模型编码 → 微调分类头

    TextCNN 核心架构

    
Input Text → Embedding → [2-gram Conv, 3-gram Conv, 4-gram Conv]
↓           ↓           ↓
Max Pooling  Max Pooling  Max Pooling
↓           ↓           ↓
Concatenate → Dense → Softmax → Category

    直觉：不同大小的卷积核捕捉不同长度的文字模式（2字词、3字词、4字词），最后综合判断。

    • 今天学完后我应该记住什么

  • **永远从简单方法开始**：TF-IDF + LR 是最快的基线，也是后续所有对比的参照物
  • **复杂方法不一定更好**：取决于数据量、任务特性、部署约束
  • **TextCNN 的核心**：多尺度卷积核 + Max Pooling，捕捉不同长度的文字模式
  • **工程化思维**：模型只是项目的一部分，数据管理、评估、部署、监控同样重要
