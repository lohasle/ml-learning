高效微调技术（LoRA / QLoRA / DPO）

概念摘要

全量微调大模型的显存需求极大（7B 模型需 80GB+），催生了一系列参数高效微调（PEFT）方法，其中 LoRA、QLoRA 和 DPO 最为重要。

核心公式

公式 含义
h = Wx + (α/r)BAx LoRA 前向传播，W 冻结，只训练 B 和 A
ΔW = B·A LoRA 权重更新，B∈R^(d×r), A∈R^(r×d)，r≪d
L_DPO = -E[log σ(β(log π_θ(y_w)/π_ref(y_w) - log π_θ(y_l)/π_ref(y_l)))] DPO 损失，直接用偏好数据优化

关键数据

方法 可训练参数 7B 模型显存 推理开销
Full Fine-tune 100% ~80GB 无
LoRA ~0.1% ~32GB 可合并，无
QLoRA ~0.1% ~16GB 需反量化
DPO ~0.1% 同 LoRA 同 LoRA

关联概念

  • RLHF（第26课）：LoRA/DPO 是 RLHF 流程的工程优化
  • 大模型训练与推理（第22课）：微调介于训练和推理之间
  • Transformer（第14课）：LoRA 通常应用于 Q/K/V/O 线性层
