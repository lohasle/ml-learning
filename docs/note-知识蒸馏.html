知识蒸馏

🎯 核心概念

1. 基础定义

  • 类型：模型压缩 / 知识迁移
  • 适用场景：将大模型的知识迁移到小模型，降低部署成本
  • 一句话定义：用大模型的 soft output 作为「软标签」训练小模型，传递类间相似关系等「暗知识」

2. 数学原理

  • 核心公式：$L = \alpha \cdot KL(p_T^{teacher} | p_T^{student}) \cdot T^2 + (1-\alpha) \cdot CE(y, p_{student})$
  • 公式直觉：学生同时向老师的「软输出」和真实标签学习，两路信号加权组合

3. 实践要点

  • Temperature T 建议从 4 开始，常见范围 4~20
  • α 通常取 0.5~0.9，教师模型越强，α 可以越大
  • 蒸馏不需要教师模型的权重，只需要推理输出 → 可蒸馏闭源 API 模型
  • 常见陷阱：T 太大导致信息模糊；α 太大导致忽略真实标签

📊 关键公式

公式 含义 直觉
$q_i = \exp(z_i/T) / \sum \exp(z_j/T)$ 带温度的 softmax T 越大，分布越平坦，暗知识越明显
$KL(p | q) = \sum p \log(p/q)$ KL 散度 两个分布的「距离」
$L_{soft} = KL(p_T | q_T) \times T^2$ 蒸馏损失 学生模仿老师的 soft output
$L = \alpha L_{soft} + (1-\alpha) L_{hard}$ 总损失 软硬标签双路指导

🔗 关联概念

  • 前置知识：Softmax、交叉熵损失（第3课）、大模型微调（第18课）
  • 后续应用：量化推理（第30课）、模型部署（第23课）
  • 同类对比：量化（改变数值精度）、剪枝（移除参数）、低秩分解（矩阵近似）
  • 与 LoRA 的区别：LoRA 是高效微调方法，蒸馏是模型压缩方法，两者可组合

💡 记忆技巧

知识蒸馏就像「名师出高徒」——老师（大模型）不只告诉你答案（hard label），还告诉你「为什么是这个答案、其他选项差多少」（soft target / 暗知识），让徒弟（小模型）学得更快更准。
