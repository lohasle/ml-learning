AI 应用架构与案例实战

概述

AI 应用架构是将模型能力转化为可运行产品的桥梁。核心挑战不是模型本身，而是如何编排多个组件、平衡延迟/成本/质量、处理真实世界的异常。

四大架构模式

模式 核心思路 复杂度 典型延迟 适用场景
单次推理 输入→模型→输出 ⭐ < 500ms 翻译、分类、摘要
RAG Pipeline 检索+生成 ⭐⭐ 1-3s 知识问答、文档分析
Agent Loop 规划→执行→观察循环 ⭐⭐⭐ 3-15s 多步推理、工具调用
Multi-Agent 多专家协作 ⭐⭐⭐⭐ 10-60s 复杂任务分解

关键公式

概念 公式 直觉
余弦相似度 cos(a,b) = (a·b)/(|a||b|) 方向一致程度
RAG 延迟 T = T_embed + T_retrieve + T_rerank + T_generate 四段累加
Agent 成本 Cost = Σ(calls × price) 步数越多越贵

架构选型决策树

需要外部知识？
├── 否 → 单次推理
└── 是 → 需要多步推理？
    ├── 否 → RAG Pipeline
    └── 是 → 需要多种专业能力？
        ├── 否 → Agent Loop
        └── 是 → Multi-Agent

关键原则

  1. 先选最简单的架构
  2. 延迟和成本是硬约束
  3. 缓存是最好的优化
  4. 可观测性是底线
