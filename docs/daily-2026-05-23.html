核心概念解释

1. 潜在空间扩散（Latent Diffusion）

传统扩散在像素空间操作（512×512×3 = 786K 维），计算量巨大。Stable Diffusion 的核心创新：先用 VAE 把图像压缩到 64×64×4 的潜在空间（16K 维），在这里做扩散，再用 VAE 解码回像素空间。

  • 压缩比：48 倍
  • 效果：消费级 GPU 就能推理，训练也变得可行
  • 代价：VAE 的压缩会丢失少量高频细节

2. UNet 去噪架构

UNet 不是普通的 CNN，它有三个关键设计： - 对称的编码-解码结构：下采样提取特征，上采样恢复分辨率 - 跳跃连接：保留低层细节（边缘、纹理） - Cross-Attention 层：在中间注入文本条件，让生成内容听从 prompt

每一步去噪，UNet 都要做一次前向传播——这就是为什么 Steps 越多越慢。

3. CFG（Classifier-Free Guidance）

CFG 是 Stable Diffusion 最精妙的调参机制：

noise_pred = noise_uncond + cfg_scale × (noise_cond - noise_uncond)

直觉理解：无条件预测是「模型的默认倾向」，条件预测是「带 prompt 的方向」。放大两者之差，就像在说「我不仅要往 prompt 走，还要走得比默认远」。

CFG Scale 行为
1.0 完全自由，忽略 prompt
7-9 平衡区，最佳效果
15+ 过度遵从，图像崩坏

4. LoRA 微调

冻结 UNet 原始权重，只在 Cross-Attention 层旁添加低秩矩阵（rank 4-64）。几 MB 权重就能学到新风格/新角色，部署时可以动态合并。

关键公式直觉

概念 公式/机制 直觉解释
VAE 压缩 512³→64²×4 把高清图压成缩略图级别的小矩阵
UNet 去噪 x_{t-1} = x_t - ε_θ(x_t, t, c) 猜测噪声长什么样，减掉它
CFG 引导 uncond + s×(cond - uncond) 放大「你要的」和「默认的」之差
DDPM 调度 β_t 从小到大 一开始慢慢加噪，后面加快
LoRA W' = W + AB (rank r) 在原权重旁搭一条小路

动手实践要点

  • Steps 调参：从 20 开始，看效果再加。50 步以上边际收益很小
  • CFG Scale：7.5 是 SD 1.5 的甜点。不同模型甜点不同
  • Negative Prompt：不只是排除，实际参与 CFG 计算，非常关键
  • Sampler 选择：Euler A 通用快速，DPM++ 2M Karras 细节更丰富
  • 显存优化：fp16 精度、xFormers 注意力优化、VAE 切片解码

常见问题

Q: 为什么 SD 要在潜在空间做扩散，不直接在像素空间？ A: 像素空间维度太高（786K vs 16K），每一步 UNet 都要处理高维张量。潜在空间把计算量降了 48 倍，让消费级 GPU 也能跑。代价是 VAE 可能丢失少量高频细节。

Q: CFG Scale 为什么不是越大越好？ A: CFG 放大的是「条件方向」和「无条件方向」之差。当 scale 过大，这个差被过度放大，导致颜色过饱和、结构崩坏。就像把音量开到最大——信号在放大，但噪声也在放大，最终失真。

Q: LoRA 微调和全量微调有什么区别？ A: 全量微调需要更新 UNet 全部 860M 参数，需要大量 GPU 显存和数据。LoRA 只训练旁路的低秩矩阵（几 MB），用少量图片就能学到新风格。代价是表达能力有限，不能学太复杂的概念。

本课总结

  1. Stable Diffusion = VAE + UNet + CLIP 三个组件的协同工作
  2. 潜在空间扩散是让扩散模型在消费级硬件上可行的关键创新
  3. CFG Scale 是最重要的调参旋钮，7-9 是最佳区间
  4. LoRA 让微调变得轻量，几 MB 权重即可个性化
  5. 部署时关注：fp16 精度、注意力优化、VAE 切片解码
