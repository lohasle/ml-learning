核心概念

论文 1：Attention Is All You Need (2017)

核心问题：RNN 必须顺序处理（无法并行）+ 长序列遗忘问题

核心创新：用 Self-Attention 替代 RNN，让每个位置都能直接看到所有其他位置

机制 公式 直觉
Scaled Dot-Product Attention $\text{Attention}(Q,K,V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$ 每个 token 问"我需要什么" → 检索所有 token → 加权汇总
Multi-Head 多组 Q/K/V 并行 多个视角同时看
Positional Encoding $PE(pos, 2i) = \sin(pos/10000^{2i/d})$ 注入位置信息

结果：WMT 英德翻译 BLEU 28.4（SOTA），8×P100 训练 3.5 天。

论文 2：BERT (2018)

核心问题：GPT-1 只能单向（从左到右）看，无法利用右侧上下文

核心创新：Masked Language Model（完形填空）实现双向编码

机制 说明
MLM 随机遮住 15% token，模型预测（必须看全局语境）
NSP 判断两句话是否相邻（理解句子间关系）
遮蔽策略 80% → [MASK]，10% → 随机词，10% → 保持原词

结果：GLUE 平均 80.4%，SQuAD F1 93.2，全面刷新 NLP 基准。

论文 3：InstructGPT (2022)

核心问题：GPT-3 能力很强但不"听话"（不按指令行事，可能输出有害内容）

核心创新：RLHF 三步流程

步骤 方法 直觉
① SFT 人类写示范 → 监督微调 教模型"好回答长什么样"
② Reward Model 多个回答 → 人类排序 → 训练打分模型 学会"哪个回答更好"
③ PPO 模型生成 → RM 打分 → 强化学习优化 用奖励信号引导模型

结果：1.3B 的 InstructGPT 在人类评估中优于 175B 的 GPT-3。

关键洞察

三篇论文代表了三个范式转移：

  1. 架构革命（Transformer）：RNN → 注意力机制
  2. 训练范式（BERT）：任务特定 → 预训练-微调
  3. 对齐范式（InstructGPT）：追求能力 → 追求可控

演进链：Transformer → {BERT (Encoder-only), GPT (Decoder-only)} → GPT-3 → InstructGPT → ChatGPT
