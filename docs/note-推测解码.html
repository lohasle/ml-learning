推测解码（Speculative Decoding）

🎯 核心概念

1. 基础定义

  • 类型：推理加速技术
  • 适用场景：大模型自回归文本生成（单条请求 latency 优化）
  • 一句话定义：用小模型快速生成候选 token，大模型并行验证，在不改变输出分布的前提下加速推理

2. 数学原理

接受条件：对于 draft 模型生成的 token $x$：

$$\text{accept if } r < \min\left(1, \frac{p_{\text{target}}(x)}{p_{\text{draft}}(x)}\right), \quad r \sim U(0,1)$$

直觉： - $p_t > p_d$：target 比 draft 更认可 → 一定接受 - $p_t < p_d$：draft 过于自信 → 按比例概率拒绝

理论加速比：$\text{speedup} \approx K \cdot \alpha + 1$，其中 $K$ 是候选长度，$\alpha$ 是平均接受率

3. 实践要点

  • Draft 模型选同系列小模型（如 7B 配 70B）
  • 候选长度 K 通常 4-8，太长反而浪费
  • 接受率 < 60% 时收益有限，不如直接自回归
  • 与量化可叠加：量化模型 + 推测解码 = 更极致加速

📊 关键公式

公式 含义 直觉
$P(x_t|x_{<t})$ 自回归条件概率 看前面猜下一个
$r < p_t/p_d$ 接受/拒绝判据 target 说了算
$K \cdot \alpha + 1$ 每轮生成 token 数 K 个候选 × 接受率 + bonus

🔗 关联概念

  • 前置知识：自回归生成、模型量化（第30课）
  • 后续应用：LLM serving 系统（vLLM、TensorRT-LLM）
  • 同类对比：Medusa（多头并行）、Lookahead Decoding（Jacobi 迭代）、Self-Speculative（早退出）
  • 核心论文：Leviathan et al. (2023) "Fast Inference from Transformers via Speculative Decoding"

💡 记忆技巧

让实习生（小模型）先打草稿，老板（大模型）扫一眼确认——对的多留，错的当场改。零质量损失，纯速度提升。
