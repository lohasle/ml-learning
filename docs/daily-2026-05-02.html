2026年5月2日 - 第24课：推理模型与思维链

今日学习主题

理解 Chain-of-Thought (CoT) 推理如何让大模型从「直觉反应」进化到「逐步思考」，以及 2024-2025 年推理模型（o1/o3、DeepSeek-R1）的核心机制——通过强化学习让模型自发学会深度推理。

为什么学这个？

前 23 课我们完成了从经典 ML 到 AI 系统工程的完整学习路线。但 AI 领域在 2024-2025 年发生了一个重要范式转变：推理能力的突破。

OpenAI o1 的发布标志着 AI 从"更大=更强"转向"思考更多=更强"。DeepSeek-R1 更是展示了 RL 训练如何让模型自发涌现推理能力。这不是提示词技巧，而是模型能力的根本性提升。

作为架构师，理解推理模型的工作原理，能帮你做出更好的技术选型——什么时候该用推理模型，什么时候用普通 LLM + CoT 就够了。

在 AI 演进中的位置：推理模型是 2024-2025 年最重要的技术突破。它标志着 LLM 从"快思考"（System 1）向"慢思考"（System 2）的跨越，是从 Transformer 架构出发的一次推理能力质变。类比人类认知：GPT-4 就像一个博学但容易出错的聪明人，而 o1/R1 更像一个会认真验算的数学家。

核心概念解释

1. System 1 vs System 2：两种思考模式

  • 直觉：你问一个人"2+3=?"，他立刻说"5"（System 1）。你问他"137×24=?"，他需要拿出纸笔逐步算（System 2）。
  • 传统 LLM 本质上是 System 1：模式匹配，快速输出，直觉驱动
  • CoT 和推理模型让 LLM 进入 System 2：逐步推理，显式化中间步骤，可验证可纠错
  • 关键洞察：System 1 擅长快速响应（聊天、翻译），System 2 擅长深度推理（数学、编程、科学分析）

2. Chain-of-Thought (CoT) 推理

  • 直觉：就像数学考试要求"写出演算过程"而不是只写答案。写过程的好处是：1）更容易发现错误 2）老师可以给部分分 3）复杂问题不可能一步到位
  • Zero-shot CoT：在提示词末尾加"Let's think step by step"，模型就会自动分步推理。2022 年 Kojima 等人发现这个简单的技巧能大幅提升推理准确率
  • Few-shot CoT：给模型几个"带推理过程的示例"，让它学会怎么推理
  • Self-Consistency：多次运行 CoT，取出现次数最多的答案（投票制）
  • 代码对应：Notebook 中模拟了 CoT 推理的逐步计算过程

3. 推理模型（Reasoning Models）

  • 直觉：CoT 是教模型"你应该这样思考"（提示词）。推理模型是让模型自己学会"我该怎么思考"（内化能力）。区别就像：跟着菜谱做菜（CoT）vs 成为厨师（推理模型）
  • 核心训练流程：
  • 预训练：和普通 LLM 一样学语言和知识
  • RL 训练：用答案对错作为奖励信号，训练推理能力
  • 涌现行为：模型自发学会回溯、验证、多路径探索
  • DeepSeek-R1 的 Aha Moment：RL 训练中，模型突然开始生成"wait, let me reconsider"这样的内容。没有人教它这么做，是训练过程自然涌现的
  • 代码对应：Notebook 中模拟了 RL 训练过程中推理链长度和准确率的关系

4. Test-Time Compute Scaling

  • 直觉：传统思路是"训练时花更多钱 = 更强的模型"。新范式是"推理时花更多钱 = 更好的回答"。就像考试——准备更久不一定考得更好（训练时扩展），但考试时给你更多时间仔细检查，成绩通常会提高（推理时扩展）
  • 两种扩展对比：
  • 训练时：模型 7B→70B→700B，成本指数增长，边际收益递减
  • 推理时：思考 100→1000→10000 tokens，成本线性增长，边际收益递减更慢
  • 关键意义：意味着你可以用中等大小的模型，通过更多推理来达到大模型的效果。这是成本效率的重大突破

5. Process Reward Model (PRM)

  • 直觉：传统 RLHF 是给整个回答打分（"这个回答好不好"）。PRM 是给推理的每一步打分（"这一步对不对"）。就像老师批改数学题，不只看最终答案，还看每一步的演算过程
  • 核心公式：PRM(step_i) = P(这一步推理是正确的)
  • 好处：不需要人工标注每一步，只要最终答案可自动验证（如数学题有标准答案），就能通过 RL 训练出推理能力

关键公式直觉

概念 公式/方法 直觉解释
CoT 准确率 P(正确) = ∏ P(step_i 正确) 每步都对才全对，步数越多越难全对
推理 token 收益 Accuracy ∝ log(thinking_tokens) 思考量翻倍，准确率增加固定量
PRM 奖励 R = Σ PRM(step_i) 每步推理都有一个正确性分数
Self-Consistency answer = mode({cot_1, ..., cot_n}) n 次推理投票，取众数
Test-time scaling cost ∝ tokens × price_per_token 推理成本 = 思考量 × 单价
Aha Moment 突然出现 "wait..." tokens RL 训练中推理能力自发涌现

常见问题

Q: CoT 和推理模型有什么区别？ A: CoT 是一种提示词技巧——你在提示词中教模型分步推理。推理模型是通过 RL 训练获得了内化的推理能力。关键区别：CoT 依赖提示词质量，推理模型自动学会思考。打个比方：CoT 像给一个学生提供答题模板，推理模型像训练出一个会独立思考的学生。

Q: 推理模型适合所有场景吗？ A: 绝对不。推理模型的代价是：延迟更高（秒级 vs 毫秒级）、成本更高（50x+ token 消耗）、不适合实时对话和简单任务。选择原则：简单任务用快速模型，复杂推理用推理模型，中间地带用 CoT 提示词。

Q: DeepSeek-R1 和 OpenAI o1 的主要区别？ A: 核心机制类似（RL 训练推理能力），但 R1 是开源的，训练细节更透明。R1 的论文展示了 RL 训练中的 Aha Moment 现象——模型自发涌现"停下来重新思考"的行为，这是非常值得关注的发现。

Q: Test-Time Compute 意味着不需要更大的模型了吗？ A: 不完全是。Test-Time Compute 是一个补充维度，不是替代。更大的基础模型 + 更多推理时间 = 最好效果。但对于资源有限的团队，用中等模型 + 更多推理时间可以达到接近大模型的效果，这是成本效率的重要突破。

本课总结

  1. CoT 是 System 2 的触发器：让模型从直觉反应转变为逐步推理，在复杂任务上准确率大幅提升
  2. 推理模型 = RL 内化的推理能力：不只是提示词技巧，而是模型真正学会了怎么思考
  3. Test-Time Compute 是新范式：推理时扩展比训练时扩展更灵活、边际收益更高
  4. Aha Moment 是 RL 的奇迹：模型自发涌现推理行为，证明推理能力可以被学习
  5. 工程选择看场景：简单任务用快速模型，复杂推理用推理模型，中间用 CoT
