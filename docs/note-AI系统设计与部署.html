AI 系统设计与部署

🎯 核心概念

1. 基础定义

  • 类型：系统工程 / MLOps / 基础设施
  • 适用场景：将训练好的 AI 模型部署为可靠的线上服务
  • 一句话定义：AI 系统不只是模型 + API，而是包含模型服务、版本管理、A/B 测试、监控告警、漂移检测、安全防护的完整工程体系

2. 核心架构模式

模式 延迟 吞吐量 适用场景
在线推理 < 200ms 中-高 搜索排序、实时推荐
异步推理 秒级-分钟级 高 LLM 生成、视频处理
边缘部署 < 50ms 低 IoT、移动端、离线场景

3. 实践要点

  • 监控四层模型：系统层（延迟/QPS）→ 模型层（准确率/置信度）→ 数据层（漂移/PSI）→ 业务层（转化率）
  • PSI 漂移检测：< 0.1 稳定，0.1-0.25 关注，> 0.25 重训练
  • 成本优化组合：量化 + 缓存 + 弹性伸缩 + 蒸馏
  • 安全纵深防御：输入过滤 + 模型安全 + 输出校验 + 监控告警

📊 关键公式

公式 含义 直觉
PSI = Σ(p_act - p_exp) × ln(p_act / p_exp) 分布差异度 越大越危险，> 0.25 必须重训练
N ≈ (Z_α + Z_β)² × 2p(1-p) / Δ² A/B 测试样本量 想检测更小的差异需要更多样本
缓存节省 = 命中率 × 单次成本 × 请求量 缓存收益 70% 命中率 = 省 70% 推理成本
P99 = Percentile(99%) 长尾延迟 100 个请求中最慢的 1 个

💡 记忆技巧

AI 系统工程 = 模型服务（怎么跑）+ 版本管理（怎么迭代）+ 监控（怎么知道出问题了）+ 安全（怎么防攻击）。就像运营一个餐厅——厨房（推理）、菜单管理（版本）、顾客反馈（监控）、食品安全（安全）。
