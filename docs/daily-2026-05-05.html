2026年5月5日 - 第27课：高效微调技术（LoRA / QLoRA / DPO）

今日学习主题

理解如何用最少的资源微调大模型——LoRA 的低秩分解、QLoRA 的量化压缩、DPO 的直接偏好优化。

为什么今天学这个？

上节课学了 RLHF，知道了大模型对齐的三阶段流程。但有个现实问题：全量微调一个 7B 模型需要 80GB+ 显存，大多数开发者根本跑不起。

LoRA/QLoRA/DPO 这三个技术，让「微调大模型」从实验室走向了普通开发者的桌面。理解它们，你就理解了 2023-2025 年大模型应用爆发的工程基础。

在 AI 演进中的位置： - 2021 年 LoRA 论文提出低秩适配，ICLR 2022 发表 - 2023 年 QLoRA 让 16GB 显存就能微调 7B 模型 - 2023 年 DPO 简化了 RLHF 流程，去掉奖励模型和 RL 训练 - 这三项技术是「大模型微调民主化」的核心推动力

与前课的关系： - 上接第26课（RLHF）→ 对齐流程完整了 - 上接第22课（训练与推理工程）→ 本课是其工程实践的延伸 - 本课 → 解决「普通人如何微调大模型」的现实问题

核心概念解释

1. 为什么全量微调太贵？

大模型参数量巨大，训练需要同时存储：模型权重 + 梯度 + 优化器状态。

模型 参数量 全量微调显存 仅权重 (FP16)
LLaMA-7B 7B ~80GB ~14GB
LLaMA-13B 13B ~160GB ~26GB
LLaMA-70B 70B ~800GB ~140GB

直觉类比：翻新一栋 100 层大楼。全量微调 = 每层都拆了重建。LoRA = 只在关键楼层加装模块。

2. LoRA：低秩矩阵分解

核心洞察：微调时权重的变化 ΔW 具有低「内在秩」。

$$h = Wx + \frac{\alpha}{r} BAx$$

其中： - $W$：冻结的原始权重（不更新） - $B \in \mathbb{R}^{d \times r}$, $A \in \mathbb{R}^{r \times d}$：可训练的低秩矩阵（$r \ll d$） - $\alpha$：缩放因子

参数量对比： - 原始：$d \times d = 4096 \times 4096 = 16.7M$ 参数 - LoRA ($r=8$)：$2 \times 8 \times 4096 = 65K$ 参数 → 压缩 256 倍

3. QLoRA：量化 + LoRA

在 LoRA 基础上引入 4-bit 量化：

技术 作用
4-bit NormalFloat 专为正态分布权重设计的量化格式
双重量化 对量化常数本身再量化
分页优化器 GPU → CPU 内存自动切换

效果：7B 模型微调从 80GB 降到 16GB。

4. DPO：直接偏好优化

RLHF 需要：训练奖励模型 → 用 PPO 做强化学习。

DPO 的洞察：可以直接用偏好数据优化策略模型，跳过奖励模型。

$$\mathcal{L}{\text{DPO}} = -\mathbb{E}\left[\log \sigma\left(\beta \left(\log \frac{\pi\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right)\right]$$

其中 $y_w$ 是优选回答，$y_l$ 是拒绝回答。

直觉理解

技术 一句话理解 类比
LoRA 只改很少参数就能微调 大楼只在关键楼层加装模块
QLoRA 压缩精度省显存 用草图而非高清图来设计改装方案
DPO 不需要奖励模型 不用请评委，直接看 A/B 测试结果改进

关键机制

LoRA 的关键设计选择

  1. 秩 r 的选择：通常 4~64，r 越大效果越好但参数越多
  2. 应用位置：通常只对 Q/K/V/O 线性层加 LoRA
  3. α/r 缩放：控制 LoRA 更新的强度
  4. 可合并性：训练后 BA 可合并进 W，推理零开销

DPO vs PPO

维度 PPO DPO
是否需要奖励模型 ✅ ❌
是否需要 RL 训练 ✅ ❌
训练稳定性 较难调 简单
数据需求 prompt + RM标注 prompt + 偏好对
效果上限 理论更高 实际接近

实践建议

如何选择方法？

显存 < 24GB → QLoRA + LoRA (r=8~16)
显存 24~48GB → LoRA (FP16, r=16~64)  
显存 80GB+ → 全量微调或大 LoRA

推荐工具链

  • PEFT (HuggingFace)：LoRA/QLoRA 实现
  • TRL (HuggingFace)：DPO/PPO 训练
  • unsloth：2x 训练速度加速

今天学完后你应该记住什么

  1. LoRA = 低秩分解：ΔW = BA，只训练两个小矩阵
  2. QLoRA = 量化 + LoRA：16GB 显存微调 7B 模型
  3. DPO = 简化版 RLHF：跳过奖励模型，直接用偏好数据
  4. 选择看资源：显存决定方法
  5. LoRA 可合并：训练后零推理开销
